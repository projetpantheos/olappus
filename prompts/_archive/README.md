# Archive des prompts

## `01_TO_10_EXECUTION_PROMPTS.md`

Archivé le 2026-09-08 par **ADR-0010**.

Ce fichier proposait une séquence d'exécution concurrente de celle des fichiers `prompts/02` → `prompts/11`, avec les mêmes numéros pour des contenus différents (03 Hélios vs Core, 04 Hermès vs Module SDK, 05 Chronos vs Muses, 06 Mnémosyne vs Hélios…). Il introduisait par ailleurs Chronos et Mnémosyne, tous deux hors P0 — Mnémosyne étant explicitement écarté par ADR-0004.

**Il ne fait plus foi.** Les prompts d'exécution applicables sont les fichiers individuels `prompts/02_BOOTSTRAP_FOUNDATION.md` → `prompts/11_NEW_MODULE.md`.

Conservé comme trace de cadrage.
