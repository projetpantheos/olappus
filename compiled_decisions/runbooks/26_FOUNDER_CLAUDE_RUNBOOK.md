# 26 — Founder ↔ Claude Code Runbook

## Session 0
Founder:
1. clone repository;
2. add kit;
3. launch Claude;
4. run Prompt 01;
5. copy report to founder review.

Founder approval only if no unresolved RED/critical contradiction.

## Session cadence
At end of every meaningful Claude session:
- tests;
- git status;
- diff summary;
- PROJECT_STATE;
- blockers;
- next action.

## Green
Claude may proceed autonomously.

## Yellow
Claude proposes and waits.

## Red
Founder must explicitly approve.

## Founder review format
GATE
STATUS
EVIDENCE
RISKS
OPEN DECISIONS
ROLLBACK
NEXT GATE

## Rule
Do not judge a feature only by whether it works.
Judge:
- product value;
- privacy;
- security;
- provenance;
- operability;
- rollback;
- cognitive load.
