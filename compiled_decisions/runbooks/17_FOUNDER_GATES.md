# 17 — Founder Gates

## GREEN — Claude autonome

- UI ;
- tests ;
- docs ;
- fixtures ;
- refactoring local ;
- bugs non critiques ;
- accessibilité.

## YELLOW — proposer puis attendre

- nouvelle table ;
- nouveau module ;
- nouvelle API externe ;
- nouvelle permission ;
- nouvelle règle métier ;
- nouvelle utilisation IA ;
- changement de rétention.

Claude fournit WHAT / WHY / IMPACT / RISKS / FILES / TESTS / ROLLBACK.

## RED — validation explicite

- production ;
- données sensibles ;
- sécurité ;
- chiffrement ;
- authentification ;
- auto-exécution ;
- finance/santé/juridique ;
- suppression massive ;
- migration destructive ;
- nouvelle catégorie de données.

## Les 5 gates

GATE DATA : cette donnée est-elle nécessaire ?
GATE TRUST : d'où vient-elle ?
GATE ACTION : quel est le risque ?
GATE CHANGE : touche-t-on un invariant ?
GATE RELEASE : peut-on démontrer que la version est sûre ?

## Escalade

Si Claude ne sait pas :
STOP, expliquer, recommander, attendre.
