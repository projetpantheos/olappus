# CTO + PRODUCT REVIEW — POINTS DE VIGILANCE

## 1. Biggest product risk

La complexité. Les modules doivent rester invisibles dans le parcours principal.

## 2. Biggest technical risk

Le couplage croisé entre modules. Le Core, les événements et les contracts doivent rester stables.

## 3. Biggest security risk

La combinaison Gmail + documents + IA. Les données privées doivent rester dans le périmètre contrôlé.

## 4. Biggest legal/product risk

Transformer une analyse en affirmation juridique. Les sources et niveaux de confiance doivent être visibles.

## 5. Biggest economic risk

Traiter chaque nouveauté avec une IA. Le Knowledge Engine doit rendre le système progressivement plus déterministe.

## 6. Biggest retention risk

Notifier trop. La réussite se mesure à l'attention évitée.

## 7. Strongest moat

Knowledge graph + provenance + Muses certifiées + règles opérationnelles + historique de cas, pas le modèle IA.

## 8. Strategic color architecture

Les couleurs identifient les intentions :

- olive : soin ;
- bronze/copper : valeur ;
- bleu profond : protection ;
- lavande : temps ;
- terracotta : foyer ;
- bleu Égée : exploration.

## 9. First “wow” moment

Importer quelques éléments du quotidien et obtenir une détection concrète, sourcée, expliquée et actionnable en moins d'une minute.

## 10. Product truth test

Le bon signe n'est pas “j'aime l'interface”, mais : **“je veux que ça surveille le reste aussi.”**
