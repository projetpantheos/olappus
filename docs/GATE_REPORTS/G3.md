## RISKS

1. **Le chiffrement applicatif L3 reste non implémenté.** Inchangé depuis G2. Aucun champ L3 n'est collecté ; à combler avant G6.
2. **Aucun test de l'application mobile.** Le choix d'outillage React Native n'est toujours pas fait — c'est ce qui rend les deux tests d'accessibilité (`TEST_MAP` 34 et 35) **non couverts**, sans qu'aucune gate ultérieure ne les débloque. À trancher avant G4.
